# حزمة الهوية الكاملة — احمد الحربي (@Ahmed014x)

## المحتويات
- html/ — نسخ تفاعلية مستقلة تعمل بدون إنترنت:
  دليل-الهوية (نظام التصميم الكامل) · عرض-الهوية (سلايدات) · تعريف-الهوية (10 بوسترات) · سلسلة-تعلم-الآلة (10 بوسترات) · سلسلة-التعلم-العميق (10 بوسترات)
- svg/ — الشعار بكل نسخه، الألوان، الأيقونات، الأنماط، ولوحة الهوية الكاملة (brand-sheet-full) + سلاسل البوسترات — كلها قابلة للسحب داخل Figma
- png/ — صور جاهزة للنشر، مرتّبة بمجلدات:
  · سلسلة-تعلم-الآلة/ · سلسلة-التعلم-العميق/ · ستوري-التعلم-العميق/
  · تعريف-الهوية/ · لقاء-معاي/ · ملصقات-تفاعل/ · شعارات/
- pptx/ — عرض الهوية قابل للتعديل في PowerPoint
- fonts/ — خط الهوية Thmanyah Sans (5 أوزان) — ثبّته قبل فتح أي ملف

## PDF
افتح html/عرض-الهوية.html في المتصفح واطبع (Ctrl+P → Save as PDF) — كل شريحة صفحة.

## الألوان
الليل #0B0D10 · السطح #171A1F · التركواز #4FD8C4 (≤10٪) · الأبيض #F2F4F6 · رمادي #8A93A0

## قواعد سريعة
نظام 8px · هامش 64-88px على 1080 · زوايا 12-20px · لون بارز واحد لكل تصميم · لا تدوير/ظلال للشعار · المساحة الآمنة = ارتفاع الشرطة
